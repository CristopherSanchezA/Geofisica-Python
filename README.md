# Geofisica-Python
# 🌊 MATLAB to Python: Geophysics Portfolio

## 🚀 Sobre este proyecto
Este repositorio documenta mi proceso de transición y dominio de herramientas computacionales para Geofísica. Aquí encontrarás ejercicios resueltos y traducidos línea a línea.

## 🛠️ Tecnologías
* **MATLAB:** Procesamiento de señales, Álgebra lineal.
* **Python:** `numpy`, `matplotlib`, `pandas`, `jupyter`.

## 📂 Estructura
Cada carpeta contiene:
1.  `script_original.m` (El código fuente en MATLAB)
2.  `script_traducido.ipynb` (La versión moderna en Python/Jupyter)
